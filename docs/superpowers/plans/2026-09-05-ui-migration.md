# 新界面功能迁移实施计划

**Goal:** 将现有 Python 媒体整理功能接入用户已完成的 React 界面。

**Architecture:** 保留新版外观及现有爬虫入口，使用仅监听本机的 Python HTTP 服务提供文件、设置、任务和日志接口。耗时任务在独立子进程执行，界面轮询真实状态，取消终止进程树。文件加载和设置读取不初始化浏览器或翻译器。

**Tech Stack:** Python 3.11 标准库、现有 requests/Playwright/下载工具、React 19、TypeScript、Vite。

- [x] `media_storage.py`：读取 JSON/NFO 与磁盘文件，设置持久化，分类规则，NFO 预览及带备份更新。
- [x] `media_worker.py` 和旧 crawler：真实任务及事件，保留原始分类，支持独立封面、截图与下载。
- [x] `media_server.py`：本地 API、队列、取消重试、静态前端与运行环境检测。
- [x] `Design app interface/src/api.ts`、`state.tsx`、`App.tsx`：统一真实状态与错误提示。
- [x] 接线媒体库、详情、任务、设置和 NFO 预览，移除演示常量。
- [x] `start_media_helper.py`、启动批处理、README：从任意当前目录运行。
- [x] 使用临时目录和中性测试数据验证读取、规则、备份、失败/取消、HTTP 与 UI；不启动真实媒体抓取，不改写现有媒体。

验收：前月默认值、12 个月可选；读取现有月目录且不写入；设置取消/保存真实有效；按钮提交真实任务；可取消、重试、查看日志；NFO 更新先真实预览且只改 tag/genre；构建及浏览器交互通过。

验证结果：58 项 Python 检查，55 通过，3 项实际符号链接用例因 Windows 权限跳过（模拟路径边界通过）。类型检查、Vite 生产构建通过。真实本地服务配合临时数据完成三种视口与完整交互验证；控制台无应用错误。现有 1—4 月 37 条记录只读加载无警告。原虚拟环境恢复并验证全部旧依赖导入。未执行外站实际抓取或视频下载。
