# 媒体下载助手 V1.0：新版界面

双击同目录 `启动新界面.bat`（原 `hinet下载.bat` 也已转到新界面）。启动程序会检查前端依赖与构建，然后打开 http://127.0.0.1:8765 。保留该终端窗口即可继续处理任务，按 Ctrl+C 停止本地服务。界面默认只监听本机；需要局域网其他设备访问时，参见 [README 的局域网访问](README.md#局域网访问) 用 `--host 0.0.0.0 --lan` 显式开启。无须启动旧 Tk 窗口。

## 使用

1. 默认显示上个月。选择年份、月份和媒体输出**根目录**，实际输出到其中的 `YYYY-MM` 目录。
2. “刷新”只读取该月 JSON、NFO 和磁盘文件，不抓取网络，也不改写历史记录。
3. “获取图片与 NFO”调用原有月度爬虫，保留 JSON/CSV 汇总；“重新下载封面”单独更新封面。图片方式支持下载、截图及两者并用；并用时截图另存为 `-screenshot.jpg`。
4. “获取图片与 NFO”“下载本月视频”或“下载所选”均留在媒体库显示进度，没有独立任务页面。当前月份进度区显示正在处理的作品、处理数量、阶段和视频下载速度，支持取消、从头重试及查看日志。每部 NFO 生成后立即发布到月份索引，图片完成后更新文件状态；中断仍保留已处理的条目。默认跳过已有视频，下载成功才替换目标文件。
5. 设置保存到 `.media-helper/settings.json`，任务和日志位于 `.media-helper/`。设置保存只影响之后加入的任务；点击取消恢复设置草稿。
6. “NFO 与标签”完整显示 Hanime1 内容标签目录（2026-09-05 核对，7 组、240 项），分类和标签共用一份选择。默认未勾选；资源本身包含且已勾选的内容同时写入 tag/genre，目录外内容不写入。支持简繁体对应、全半角和英文大小写匹配；不从作者、厂商或本地记录补充目录。旧设置中仍属于网站目录的勾选会保留。新抓取保存 `original_tags`；历史文件缺失的原始标签不能凭空恢复。
7. 应用到已有 NFO 会先给出真实预览；确认后只更新分类字段，可备份原文件为 `.nfo.bak`（已有备份时另建唯一文件）。预览后文件或规则有变动会拒绝更新，需重新预览。
8. “分辨率”位于图片状态左侧，优先显示下载页最高可用画质（如 1080p）。未查到下载页画质时显示未知，不以播放链接画质代替最高画质；表头刷新按钮可补查本月下载页。获取图片与 NFO 时也会保存画质信息，不受标签勾选影响。它表示来源画质，不是本地视频文件的实测分辨率。

## 环境

Python 3.11+、Node.js 22.12+ 或 24+、pnpm。启动脚本优先使用项目 `.venv` 中可用的原有依赖，环境不可用时回退到当前 `python`。迁移时修复了 `.venv/pyvenv.cfg` 中另一台机器的 Python 路径，原配置保存在 `.venv/pyvenv.cfg.pre-ui-migration`。若缺少 Python 依赖，运行 `python -m pip install -r requirements-media-helper.txt`。项目同级 `bin` 中的 FFmpeg/yt-dlp 与 `ms-playwright` 中的 Chromium 优先使用。

“设置 → 高级”显示实际依赖检测结果，并提供网络代理：开关默认关闭；地址支持 `http://用户:密码@主机:端口`、`http://主机:端口`、`socks5://主机:端口` 等形式，可先用“测试代理连通”按钮验证。开启后月份爬虫、画质查询、截图、封面图片与视频下载（含 Playwright、requests、yt-dlp、ffmpeg 各出口）统一经由代理；`127.0.0.1`、`localhost` 与局域网地址始终直连，界面访问不受影响。关闭开关后代理地址会保留，便于再次启用。翻译保留原有的在线服务和 Argos 离线回退；两者都不可用时保留原文。网站连接、验证页面或下载源错误会进入失败状态并留下日志。

网站月份页没有返回作品时，首页会显示失败原因及网站月份页链接，不会标为完成或写出空索引。2026-05 的空 JSON/CSV 是旧版误判成功留下的文件，不能视为已下载的资源。

## 开发与验证

后端：`python media_server.py --no-browser`。

前端目录执行 `pnpm dev`，地址 http://127.0.0.1:8443 ，API 代理到 8765。生产界面由 Python 服务直接提供。

根目录执行 `python -m unittest discover -s tests -v`；前端目录执行 `pnpm typecheck` 和 `pnpm build`。测试使用临时目录和中性样例，不访问真实下载源，不修改现有媒体。
